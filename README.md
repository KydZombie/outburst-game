# Outburst
A card-fighter game where emotions effect the game.

Currently, the game features a cast of 4 characters fighting using a deck of cards against "Jeff," who will hurl attacks at your team. Manage your teams emotions to keep them from getting too sad and hurting their damage output, and angry enough that they can land devastating punches.

The game features 3 difficulty levels, allowing for an experience catered to the player.

## Build Requirements
- .NET 8+
- Godot Mono 4.6.1

## How to Build & Run
### Terminal Version
- Clone repo
- `cd Terminal`
- `dotnet build` to build (Executable will be in `./bin/Debug/net8.0`) OR `dotnet run` to run immediately

### Godot Version
- Clone repo
- Open project in Godot
- Run project
